# 0.2.0-alpha.12

English | [中文](#中文)

Alpha 12 is published through the existing protected OIDC workflow on npm `alpha`; `latest` remains `0.2.0-alpha.10`. Registry version/alpha, matching tag/non-draft prerelease and archive integrity were independently read back. The public archive is byte-identical to the fifteen-Host package. See [publication evidence](../agent-notes/alpha12-final-acceptance.md#published-archive-readback).

- **Exact stock DSH `0.2.2-alpha.3`:** adds this one exact Host alongside the prior fourteen versions. Alpha.1, alpha.2, future releases and mixed package sets are not inferred supported. New Cordis search registration uses its effective configuration identity while preserving the legacy path and Host-owned route changes. No Host fork or changed system permissions is required.
- **Luna Reserve is retired on every Host:** old `enableReserveFallback` values are accepted but inert. They cannot enable background polling, usage negotiation or model/account switching. The old `gpt-reserve` model is rejected before account access or network requests with a message asking the user to explicitly select an ordinary model. Existing return files are not read, migrated or deleted. Ordinary account UI, read-only quota tools, cache isolation, cancellation and failure cooldown remain.
- **Saved Task recovery on alpha.3:** inspection, authenticated Stop/manual takeover and the existing strictly checked delegation-disable/archive exits remain. Automatic routing, resume and delegation recovery fail closed, including direct internal entry points. Old owner/session/revision checks, counters, receipts, ledger fencing and truthful child cleanup remain; unconfirmed cleanup is not treated as success. Original fourteen-Host behavior is retained. Task public activation remains closed everywhere; this does not reopen frozen Task development.
- **Issue #417 B:** omit unsupported `temperature`, including the stock Auto review preset's zero value, only at the Codex Responses payload boundary after caller callbacks. Preserve other fields, caller-owned data, error propagation and foreign provider/API configuration. The preset still uses the session model. This does not install a dedicated first-stage reviewer or change authorization.
- **Issue #417 A remains unresolved:** published alpha.3 exposes a general LLM waterfall with purpose/session metadata but no supported replacement risk backend carrying one authenticated pending execution and cancellation contract. The plugin does not treat strings as authority or broaden shell, escalation or out-of-workspace eligibility. See [Auto-review](../auto-review.md).

## Migration and verification

Select an ordinary model explicitly for a conversation still using `gpt-reserve`; if the Host cannot replace that saved selection, preserve it and start another conversation with the chosen model. Do not delete saved sessions, Task state, return files or OAuth credentials. On alpha.3, inspect and stop or take over old Task state manually through authenticated controls; do not attempt automatic resume. No reauthorization or daily Host upgrade is requested by this release.

Final acceptance must identify this version's source and the same packed artifact across all fifteen exact Hosts, including the original fourteen full profiles and alpha.3's explicit recovery-only profile. Earlier Alpha 11 and development-package hashes are historical evidence, not this release's archive identity. Offline/installed synthetic checks do not establish real-account/model, Windows Desktop, native GUI or performance acceptance. Computer Use #402 and unrelated dependency PRs are not included. All optional feature defaults remain off.

## 中文

Alpha 12 已通过原有受保护 OIDC 工作流发布到 npm `alpha`，`latest` 保持 `0.2.0-alpha.10`。npm 版本／alpha、匹配的标签／非 draft prerelease 和归档完整性均已独立回读，公开归档与十五 Host 验收包逐字节一致。参见[发布证据](../agent-notes/alpha12-final-acceptance.md#published-archive-readback)。

- **精确适配 stock DSH `0.2.2-alpha.3`：** 保留原十四个版本，仅增加这个精确 Host；不推断支持 alpha.1、alpha.2、未来版本或混合包。新版 Cordis 搜索注册使用其生效配置身份，保留旧版路径和 Host 自己的路由修改。无需 Host 分叉或修改系统权限。
- **所有 Host 上退役 Luna Reserve：** 旧 `enableReserveFallback` 配置可读取但不再生效，不会恢复后台轮询、usage 协商或自动切换模型／账户。遗留 `gpt-reserve` 在读取账户或网络请求之前明确拒绝，并提示用户自行选择普通模型。旧 return 文件不读取、不迁移、不删除；普通账户界面、只读额度工具、缓存隔离、取消和失败冷却保留。
- **alpha.3 上旧 Task 仅恢复：** 保留查看、经过身份校验的停止／转手动，以及原有严格校验的停用委派／归档退出。自动路由、续跑和委派恢复明确拒绝，内部直接入口也不能激活。owner／会话／revision 校验、计数、回执、ledger fencing 和真实子任务清理义务保留；清理未确认不能算成功。原十四个 Host 行为不变，所有版本的 Task 公共激活入口继续关闭，不重开冻结开发。
- **修复 #417 B：** 仅在 Codex Responses 的 payload 回调之后移除不支持的 `temperature`，包括自带 Auto review preset 的零值；保留其他字段、调用者数据、错误传播及其他 provider/API 的配置。preset 仍使用会话模型，不表示已经切换专用首阶段 reviewer，也不改变授权。
- **#417 A 尚未解决：** 已发布 alpha.3 提供通用 LLM waterfall 和 purpose／会话元数据，但没有携带可信待执行动作及取消绑定的风险后端替换接口。插件不把字符串当权限，不扩大 shell、提权或工作区外调用范围。参见[自动审阅说明](../auto-review.zh.md)。

遗留 `gpt-reserve` 会话需要用户明确选择普通模型；若 Host 无法修改该旧会话的选择，请保留会话并用所选普通模型另开会话。不要删除会话、Task 状态、return 文件或 OAuth 凭据。在 alpha.3 上通过经过身份校验的控制查看、停止或转手动，不尝试自动续跑。本次发行不要求重新授权或升级日常 Host。

最终验收须绑定本版本源码和十五个精确 Host 使用的同一个发布包，包括原十四个完整测试档及 alpha.3 的明确仅恢复测试档。旧 Alpha 11 和开发包哈希不能替代新包。离线／隔离安装合成测试不代表真实账户、模型、Windows Desktop、原生 GUI 或性能验收。Computer Use #402 和无关依赖 PR 不包含在内，所有可选功能默认仍关闭。
