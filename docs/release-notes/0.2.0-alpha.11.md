# 0.2.0-alpha.11

Alpha 11 combines exact DSH rc.4/rc.5 compatibility, GPT-6.1 Terra, the unified speed menu, original-image fork handling and bounded native bili preflight observation. All fourteen declared exact Hosts remain covered. The npm publication channel is `alpha`; `latest` must remain on Alpha 10. Until publication is verified, Alpha 10 remains the confirmed installation recommendation and its immutable archive still rejects rc.4/rc.5.

- **Exact rc.4 compatibility:** extends the exact peer declarations, packaged compatibility contract, shared Host/browser policy and verification catalog. Comparing all 592 rc.3/rc.4 DSH npm archives found no required functional adapter change. The original stock installer refusal, integrity inventory and consumed-API review remain in the [initial compatibility evidence](../agent-notes/dsh-021-rc4-compatibility.md).
- **GPT-6.1 Terra:** adds the missing `gpt-6.1-terra` catalog entry through the existing ChatGPT OAuth Responses adapter, with text/image input and tool calls. The Codex-derived fallback uses a 500,000-token context default and 872,000 local override ceiling. Low, Medium, High, Xhigh and Max are selectable; Default omits an effort override, and unsupported Off/Minimal/None/Ultra values are rejected before authentication or dispatch. Existing model defaults and future native Terra metadata remain preserved. See the [model integration record](../agent-notes/gpt61-terra-support.md).
- **Unified conversation speed menu:** every eligible Codex GPT model now uses the same compact Standard/Fast/Ultrafast control. Terra and other models without Ultrafast keep Standard and Fast, while a disabled Ultrafast row explains the model-specific reason through English/Chinese touch-reachable information. Request deadlines, session replacement, cancellation and explicit-read recovery remain covered. Ultrafast stays gated to exact Astra/Sol61 models and the existing account/selection checks; neither account entitlement nor actual served tier is inferred.

- **Exact rc.5 compatibility:** adds the next exact Host while retaining all prior versions and mixed-peer refusal. The scoped official-package comparison and signature-aware reasoning `rawText`/display `text` regression are documented in [rc.5 evidence](../agent-notes/dsh-rc5-compatibility.md).
- **Original images in seeded forks:** inherited original bytes remain accessible inside the verified inherited prefix when the Host marks fork history as seeded. Invalid prefix metadata, early forks, live-tail inheritance and unrelated sessions remain denied; generation/edit, authentication and image-source ownership checks stay required.
- **Bounded bili preflight:** explicit opt-in can observe the already-installed native interception route during compression. It requires the exact numeric-loopback origin, active fetch/state identity, exact downstream URL, no redirect, successful SSE and the exact preflight header. Headers alone grant no authority. Only recognized heartbeats renew idle time; the absolute budget remains bounded at 900,000 ms, and semantic output/cancellation restores ordinary behavior. This does not fix separate repeated-413 or pending-compression-receipt issues.
- **Direct HTTP dependency:** raises the product Undici minimum to `^8.12.3` and locks it to `8.12.3`. Other transitive Undici copies are not claimed upgraded. Cancellation, response disposal and dispatcher ownership regressions remain required.

The October 28 [13-Host joint acceptance](../agent-notes/alpha11-joint-acceptance.md), its `d8edd` archive and earlier rc.4-only archives are historical evidence, not acceptance for this final package. The final release must record a new frozen source, complete checks, browser results, identical-artifact fourteen-Host matrix and pack/hash readback. See [final release acceptance](../agent-notes/alpha11-final-acceptance.md).

Selecting Terra does not implement Computer Use, install a desktop driver, grant screen/input permission or provide a reusable Terra executor for conversations using another main model. Those capabilities remain separate work. Except for the direct Undici floor/lock update above, development SDK, Node range, model defaults, optional capability defaults, cancellation, Host-owned Search selection and Task pause remain unchanged. No exemption, forced installation or security-check change is used. Keyless fixtures and Chromium tests do not establish real OAuth/model access, physical Desktop/iPhone, Safari/VoiceOver, billing, served tier or full user acceptance. Computer Use #402 and stock alpha.2 Reserve support are excluded. No deployment, daily installation, Host upgrade or service restart is included. After the protected publication and readback succeed, the exact plugin install target is `dsh-codex-connect@0.2.0-alpha.11`; publication is separate from real-account/Desktop acceptance.
