# 0.2.0-alpha.13

English | [中文](#中文)

Alpha 13 is a release candidate for exact stock DSH `0.2.2-rc.1`. This source document is not publication evidence. Public installation recommendations remain on published Alpha 12 until the new npm version, `alpha` tag, matching Git tag and prerelease, and archive integrity have been independently verified. The plugin `latest` channel is unchanged.

- **One exact additional Host:** retain the prior fifteen declared versions and add only `0.2.2-rc.1`. This does not infer support for other prereleases, future versions, or mixed DSH package sets. Version gates, peer declarations and installed-package checks remain exact.
- **Saved Task recovery stays restricted:** both `0.2.2-alpha.3` and `0.2.2-rc.1` use the recovery-only profile. Inspection, authenticated Stop/manual takeover and the existing checked disable/archive exits remain. Automatic routing, resume and delegation recovery fail closed. Existing ownership, session, revision, receipt, ledger and child-cleanup checks remain. The original fourteen Hosts retain their prior contract; Task public activation and all optional defaults stay off.
- **Safer compatibility fixtures:** resolve each exact Host installation without weakening peer checks. Bound transient registry retries and reject malformed metadata rather than treating it as a supported version.

## Verification and migration boundaries

Before release, the Alpha 13 package must pass the full offline check, browser regression and every declared exact Host installation with an identical packed artifact. The protected release workflow must also verify successful CI for its exact main commit and publish that same verified archive through the existing OIDC publisher. Earlier Alpha 12 or PR development-package results are not Alpha 13 archive evidence.

Isolated synthetic checks do not establish real-account/model, native GUI, Windows Desktop or performance acceptance. No daily Host upgrade, service restart, account reauthorization or new permissions are required or performed by preparing this release. Preserve saved sessions, Task state, return files and OAuth credentials. On recovery-only Hosts, inspect and stop or take over old Task state through authenticated controls; do not attempt automatic resume. Computer Use #402, unrelated dependency updates and the unresolved replacement Auto-review backend in #417 A are not included.

## 中文

Alpha 13 是精确适配 stock DSH `0.2.2-rc.1` 的发布候选。本源码文档不是发布证据。在独立核实新 npm 版本、`alpha` 标签、匹配的 Git 标签及 prerelease 和归档完整性之前，公开安装建议仍使用已发布的 Alpha 12。插件 `latest` 通道不变。

- **仅新增一个精确 Host：** 保留原十五个声明版本，只新增 `0.2.2-rc.1`，不推断支持其他预发布版、未来版本或混合 DSH 包。版本门禁、peer 声明和隔离安装检查保持精确。
- **旧 Task 仍仅恢复：** `0.2.2-alpha.3` 和 `0.2.2-rc.1` 都使用仅恢复测试档。保留查看、经过身份校验的停止／转手动，以及原有严格校验的停用／归档出口；自动路由、续跑和委派恢复明确拒绝。owner、会话、revision、回执、ledger 和子任务清理校验保留。原十四个 Host 保持原有契约，Task 公共激活入口和所有可选功能默认仍关闭。
- **更稳妥的兼容测试环境：** 解析精确 Host 安装而不放宽 peer 检查。限制注册表临时失败的重试次数，不把格式错误的元数据当作支持版本。

发布前，Alpha 13 必须通过完整离线检查、浏览器回归及所有声明 Host 的隔离安装，并证明使用同一个发布包。受保护发布工作流还须核验精确 main 提交的成功 CI，再由现有 OIDC 发布器发布同一验收归档。旧 Alpha 12 或 PR 开发包结果不能替代 Alpha 13 归档证据。

隔离合成测试不代表真实账户／模型、原生 GUI、Windows Desktop 或性能验收。准备本版本不要求也不会升级日常 Host、重启服务、重新授权账户或增加权限。保留会话、Task 状态、return 文件和 OAuth 凭据；仅恢复 Host 上应通过经过身份校验的控制查看、停止或转手动，不尝试自动续跑。Computer Use #402、无关依赖更新及 #417 A 尚未解决的 Auto-review 后端替换不包含在内。
