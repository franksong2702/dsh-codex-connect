# 0.2.0-alpha.1 — GPT-6.1 Sol and simpler plugin numbering

This Alpha adds `gpt-6.1-sol` to the manual model catalog and configuration selector through the existing Codex OAuth adapter. Low, Medium, High, Xhigh, and Max are available; Default leaves effort unspecified. Unsupported effort values are rejected before authentication. Native provider metadata is preserved when the model is already present. Ultra orchestration is not supported.

The Codex catalog default remains 272,000 tokens with an optional 872,000 local configuration ceiling. These are catalog/configuration values, not measured account capacity. Model access depends on the account. The maintainer reports a successful real request on the existing 3081 environment; automated regression uses synthetic requests and does not establish cross-account access.

## Independent numbering

`0.2.0-alpha.1` begins the shorter `0.2.0-alpha.N` plugin sequence and sorts above `0.1.0-alpha.4.54`. The earlier `0.1.0-alpha.4.55` candidate was not published. Existing releases, tags, compatibility records, and update-highlight history retain their identities.

This is a naming cleanup, not a narrower host compatibility promise, a host upgrade, or a Beta/stable promotion. The declared DSH targets remain `0.1.7-rc.1`, `0.1.7-rc.2`, `0.2.0-rc.1`, and `0.2.0-rc.2`. After publication and independent artifact verification, the maintainer separately approved promotion of npm `latest`. As of 2026-10-01, both `alpha` and `latest` point to `0.2.0-alpha.1`; default installation selects this Alpha, not a stable release. Checking for updates does not install them.

## Installation after publication

Use the existing profile name in place of `web`:

```sh
dsh plugin --profile web add dsh-codex-connect@0.2.0-alpha.1
```

No configuration or stored-data migration is required by the numbering change. Repository README recommendations now select this independently confirmed published pairing. The immutable npm archive retains the README prepared before publication. Exact verified pairings are recorded in [the compatibility catalog](../../verified-compatibility.json); [PR #299](https://github.com/franksong2702/dsh-codex-connect/pull/299) records final verification.

This addresses the GPT-6.1 Sol availability part of [#298](https://github.com/franksong2702/dsh-codex-connect/issues/298) using a catalog fallback. It does not upgrade the full pi-ai/OAuth dependency or close that broader request. Adaptive Task remains paused and experimental defaults remain off.
