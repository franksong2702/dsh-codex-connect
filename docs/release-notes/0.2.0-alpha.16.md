# Codex Connect 0.2.0-alpha.16

Alpha16 adds DSH `0.2.2-rc.4` / `0.2.2-rc.5` host compatibility checks
and GPT-6.2 Astra / Sol catalog entries. The two newer DSH hosts require Node
24.9.0 or newer; this does not establish account entitlement to either model.

the verified original artifact. The npm publication succeeded; the initial

completed via metadata recovery without publishing the npm package again.

## Isolated verification of the published archive

On M15 with Node 24.15.0, the exact public Alpha16 archive installed into
a disposable profile on stock DSH `0.2.2-rc.5`. The profile booted with
unchanged defaults, doctor reported a compatible host and Alpha16 both loaded
and installed, and the keyless runtime checks prepared 14 models and covered
10 isolated native compaction fixture processes. This records only the
published Alpha16 + DSH `0.2.2-rc.5` pair; it does not extend the record to
other DSH versions or establish real OAuth, provider calls, native Desktop,
or Windows acceptance.

For that exact host, install the published version into a compatible profile:

```sh
dsh plugin --profile web add dsh-codex-connect@0.2.0-alpha.16
```

This evidence does not itself move npm `latest` or change the repository's
default installation recommendation.
