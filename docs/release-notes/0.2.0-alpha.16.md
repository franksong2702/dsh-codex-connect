# Codex Connect 0.2.0-alpha.16

Alpha 16 adds GPT-6.2 Astra and Sol to the manual model catalog and adds source-level verification for DSH `0.2.2-rc.4` and `0.2.2-rc.5`. The two hosts require Node `>=24.9.0`. The compatibility catalog records the public package pairing independently verified below. [Source changes and CI](https://github.com/franksong2702/dsh-codex-connect/pull/459)

## Published package verification

On 2026-11-19 the npm archive was downloaded and compared byte for byte with the original GitHub workflow artifact for source `ada191aa960b80a1c26472d37a64438c66173e07`. npm SHA-512 and SHA-1 also matched. The archive contains 74 files and 1,492,831 bytes. Its SHA-256 is `fef8fd07a1e83d6ea01591788c99d618ebf6a9024159f96cd02c666b1f18f43c`. [Release artifact](https://github.com/franksong2702/dsh-codex-connect/actions/runs/44482730827/artifacts/14508852783) · [GitHub prerelease](https://github.com/franksong2702/dsh-codex-connect/releases/tag/v0.2.0-alpha.16)

With stock npm DSH `0.2.2-rc.5`, Cordis `4.1.0` and Node `24.13.0` on macOS arm64, the stock CLI installed the exact public release in a clean Web profile:

```sh
dsh plugin --profile web add dsh-codex-connect@0.2.0-alpha.16
```

All 74 installed files matched the public archive. Web loaded, `doctor --json` reported a compatible pairing with no credential file, and the loopback model endpoint listed all 14 models, including GPT-6.2 Astra and Sol. All 14 passed request preparation. The installed-runtime check passed synthetic image, retry, preflight and recovery checks with zero real provider requests. The profile kept its default model, Search routing and optional feature defaults. Real OAuth, real model calls and native-device acceptance remain unverified.

At verification, npm `alpha` pointed to `0.2.0-alpha.16` and `latest` pointed to `0.2.0-alpha.15`. The public compatibility record adds the exact `rc.5` pairing. Default-channel promotion requires separate approval. [Promotion and rollback procedure](../../RELEASING.md#promoting-latest-short-lived-interactive-authentication)

2026-11-19，公开 Alpha 16 归档与原始发布产物逐字节一致。在原版 DSH `0.2.2-rc.5` 的全新隔离 Web profile 中，安装、加载、诊断及 14 个模型的无凭据请求准备均通过。这次公开包精确安装验证时，默认安装标签指向 Alpha 15。真实账号及实体客户端验收待确认。
