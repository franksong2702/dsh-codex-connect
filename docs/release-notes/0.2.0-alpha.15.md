# Codex Connect 0.2.0-alpha.15

Alpha15 adds exact DeepSeek Harness `0.2.2-rc.3` compatibility while retaining all seventeen previous supported hosts. It includes the repair from #438 for the installation alert in #436.

A support declaration alone allowed installation but left authenticated retained-session readback, Stop and manual takeover blocked with `TASK_HOST_OWNERSHIP_UNVERIFIED`. Retained v2 state could also block an unrelated ordinary request. Exact rc.3 now uses the existing subagent ownership query, with matching core and subagent package identities required. Missing, mixed or foreign metadata still fails closed.

Public Task and automatic delegation remain disabled. Saved-state recovery, owner and revision checks, cancellation, spent counters and ordinary requests retain their existing obligations. No dependency pins, Node range, feature defaults or daily services are changed.

The repair passed the eighteen-host packed installation/runtime matrix, full local check, independent Astra review and exact-head PR CI. The newly numbered release artifact must pass its own checks before publication; the earlier local Alpha14 comparison archive is not this release package. Synthetic checks do not establish real OAuth/model, Desktop or physical Windows acceptance.

After npm publication is confirmed, install the exact version into an existing compatible profile:

```sh
dsh plugin --profile web add dsh-codex-connect@0.2.0-alpha.15
```

Publication moves only the npm `alpha` channel. `latest` remains unchanged; no host upgrade, service restart or experimental activation is part of this release. Previously published versions and tags retain their original identities.
