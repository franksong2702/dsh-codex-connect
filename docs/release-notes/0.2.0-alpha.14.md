# 0.2.0-alpha.14

English | [中文](#中文)

Published on 2026-11-13. Exact source, registry archive and GitHub prerelease have been independently verified.

## Changes and boundaries

- Improve input-area control stability (#426).
- Add only exact stock DSH `0.2.2-rc.2`, retaining the sixteen prior Hosts. Mixed package sets and unlisted versions remain unverified. The recommended Host stays `0.2.1-rc.5`; existing supported Hosts do not require an upgrade.
- Use the official Host ownership contract and close a retained Task recovery bypass across providers (#433). Managed descendants cannot bypass the recovery fence through another adapter. Public Task and automatic delegation remain frozen; authenticated safety exits, saved state, cancellation and accounting remain intact.
- Include scoped jsdom/Undici and fast-uri maintenance (#414/#413), development dependencies (#429), and pinned workflow Actions (#430). Exclude #391, #394 and Computer Use #402.

## Verification and installation

The [original publication](https://github.com/franksong2702/dsh-codex-connect/actions/runs/43361438331) verified and uploaded the package, but its twelve registry readback attempts returned 404 and the job failed. It was not rerun. The [recovery-only run](https://github.com/franksong2702/dsh-codex-connect/actions/runs/43362266370) succeeded without npm republication or tag promotion. The non-draft [GitHub prerelease](https://github.com/franksong2702/dsh-codex-connect/releases/tag/v0.2.0-alpha.14), published at `2026-11-13T03:57:28Z`, and tag `v0.2.0-alpha.14` target exact release SHA `e06ed3c14759244cc10f8dcfbccb19ac5e6f51f6`.

Independent download verification matched the public npm archive byte-for-byte to original artifact `14008871329`: SHA-256 `706a31168ecf1981fb49844dc6df71d61d0fe89e54cb1120135840c58ff25c47`, 1,480,473 bytes and 74 files, with matching registry SHA-512/SHA-1. [Exact-main CI](https://github.com/franksong2702/dsh-codex-connect/actions/runs/43355752914) and [CodeQL](https://github.com/franksong2702/dsh-codex-connect/actions/runs/43355752040) passed; both Node versions checked the same archive on all 17 exact Hosts. The immutable published archive retains its pre-publication recommendation; this documentation update does not republish it. At the 2026-11-13 readback, npm `alpha` was `0.2.0-alpha.14` and `latest` remained `0.2.0-alpha.10`. Final read-only recovery verification returned `already-complete`, with `npmRepublished=false` and `tagsPromoted=false`.

The candidate record reports 17/17 exact Hosts using identical Alpha14 archive bytes, 2,505 passing tests with two existing skips and 101 browser tests. Candidate production audit found zero vulnerabilities; the full audit retained one existing moderate development-only minimatch advisory. These recorded candidate checks are not new published-package installation, Desktop, OAuth, live-model, native-keyring, HMR or performance acceptance.

Select an exact supported Host from [INSTALL.md](../../INSTALL.md) and use the intended existing profile in place of `web`:

```sh
dsh plugin --profile web add dsh-codex-connect@0.2.0-alpha.14
```

No deployment, daily-service restart, automatic Host upgrade, npm latest promotion or account reauthorization is included. Preserve saved sessions, Task state, return files and OAuth credentials. On recovery-only Hosts use authenticated inspection, Stop or manual takeover, not automatic resume.
