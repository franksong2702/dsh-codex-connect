# Astra experimental history migration

Pre-release Astra reasoning updates added `reasoningUpdate` and sometimes `reasoningSelectionSeq` to the host's generic plugin notice source. The frozen v0-to-v1 migrator rejects those extra members. A new source discriminant is also insufficient: v1-to-v2 refuses an unclassified source when remapping event references.

New approvals use the supported plugin snapshot form. A named section stores the validated approval as JSON; an optional section stores the one-based ordinal of the acknowledged `model/selection`, not its format-dependent event sequence. The model-visible notice, request positions and wire effort remain unchanged. Readers still recognize legacy provenance on hosts able to load it. User or model text never grants approval.

`lib/astra-history-repair.js INPUT.jsonl[.zstd] NEW-OUTPUT.jsonl[.zstd]` prepares a new private artifact, never an in-place replacement. It reads every concatenated Zstandard frame, validates exact legacy approval fields and notice text, converts both queued and admitted occurrences, and preserves all other rows. Unknown locations, malformed approvals, foreign session IDs, missing manual-selection references, trailing compression damage and existing output paths fail closed. The utility is for stopped experimental histories only; it is not an automatic startup hook or a general host-format migrator. Use the target host to validate the complete output before installing it under separately approved maintenance.

Unit tests run the real released v0-to-v3 chain, including first-edge rejection of legacy metadata. File tests cover concatenated frames, exclusive output and unchanged input. A private history was also checked locally against installed 0.1.5-rc.1 and 0.1.6-alpha.1 catalogs: both restored the repaired artifact while the original failed. Private content is not included in fixtures or this repository. Browser acceptance and deployment remain separate; this change does not widen supported-host metadata or publish the experimental feature.
