# Codex Connect — Images

English | [中文](docs/README.zh.md)

Optional image generation for [Codex Connect](https://www.npmjs.com/package/dsh-codex-connect) in DeepSeek Harness.

This package is a private PR-1 skeleton. It installs an enabled configuration row but deliberately registers no image tool, browser card, route, or network request. Do not publish or install it as a functional plugin yet.

The completed add-on will remain a separate npm package so users can keep the core Codex Connect provider without installing image generation. Images are generated by the Codex upstream endpoint. The upstream decides which model runs; this plugin does not specify it and makes no claim about it.

## Safety boundary

- Community Alpha; not endorsed by DeepSeek or OpenAI.
- No credentials, account IDs, OAuth URLs, or full prompts belong in issues or logs.
- The add-on will not change the default model or search route.
- Image generation may consume additional quota, and cancellation may stop only local waiting.

See the repository's [versioned v4 design](../../docs/design/codex-connect-images-v4.md) before contributing to later implementation PRs.
